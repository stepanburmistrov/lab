## 🚀 Как пользоваться

1. Выберите интересующий эксперимент в таблице.
2. Откройте `README.md` конкретного раздела: там схемы подключения, зависимости и пояснения.
3. Скачайте отдельный файл или весь репозиторий через **Code → Download ZIP**.
4. Повторите эксперимент и измените параметры — так интереснее.

> ⚠️ Примеры для реального оборудования проверяйте сначала в безопасных условиях. Пины и питание могут отличаться между ревизиями устройств.
